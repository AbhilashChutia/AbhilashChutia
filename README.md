I'm a full-stack developer with a deep interest in AI/ML and cybersecurity. My programming journey started back in high school and really took shape through my BCA at Jagannath Barooah University and subsequent MCA at Tezpur University. I enjoy the entire spectrum of web development—from designing clean, intuitive user interfaces to architecting robust, scalable back-end systems.
